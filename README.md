# Local LLM Assistant

Chat with a local LLM via LM Studio's OpenAI-compatible API.

## Prerequisites

- IntelliJ IDEA 2025.2.x or later
- Java 17 or later

## Installation

1. Clone the repository.
2. Import the project into IntelliJ IDEA.
3. Build and run the plugin.

## Running Tests

To run all test cases, use the following command in your terminal:

```sh
mvn test
```

Alternatively, you can run tests directly from IntelliJ IDEA:
- Navigate to `Test` > `Run 'All Tests'`.

This will execute all the tests in the project.
